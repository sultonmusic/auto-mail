    Auto Mail to'g'ridan-to'g'ri brauzerdan Gmail API bilan ishlaydi. Serversiz ishlashi uchun o'zingizning Google OAuth Client ID raqamingiz kerak — u maxfiy kalit emas.

    Client ID qanday olinadi? (5 qadam)
    1. console.cloud.google.com da yangi loyiha oching.
    2. «APIs & Services → Library» da Gmail API ni yoqing.
    3. «OAuth consent screen» da tashqi (External) turini tanlang va o'z Gmail manzilingizni Test users ga qo'shing.
    4. «Credentials → Create credentials → OAuth client ID → Web application» tanlang.
